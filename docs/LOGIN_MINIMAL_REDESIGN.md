# 🎨 登录页面极简重设计

## 🎯 设计理念

**核心原则**: 减少选择，优化体验

用户在登录时面对太多选择会产生"选择疲劳"。新设计遵循：
- **主要路径明确**: Google 一键登录（最简单）
- **智能检测**: 一个输入框自动识别手机号/邮箱
- **渐进式披露**: 密码登录折叠起来（减少视觉干扰）
- **流畅动画**: 自然的状态切换

## 🚀 新功能特性

### 1. **智能输入检测**

输入框自动识别手机号还是邮箱：

```typescript
// 输入: +1 (613) 555-1234
→ 检测为手机号
→ 自动格式化
→ 提示: "📱 将发送短信验证码"

// 输入: user@example.com
→ 检测为邮箱
→ 提示: "📧 将发送邮件验证码"
```

**用户体验**:
- 无需选择"手机号"或"邮箱"标签
- 输入什么自动识别
- 实时提示发送方式

---

### 2. **Google 登录优先**

```tsx
// 设计突出 Google 登录
<button className="w-full ... bg-white border-2 hover:border-primary hover:shadow-md">
  [Google Logo] 使用 Google 登录
</button>
```

**优势**:
- 一键登录，无需填表
- 所有用户都有 Gmail
- 最快的登录方式

---

### 3. **密码登录折叠**

```tsx
<button onClick={() => setShowPasswordLogin(!showPasswordLogin)}>
  使用密码登录 ▼
</button>

{showPasswordLogin && (
  <form>
    <input type="email" />
    <input type="password" />
    <button>登录</button>
  </form>
)}
```

**优势**:
- 默认隐藏，减少视觉干扰
- 需要时点击展开
- 保留功能，不影响老用户

---

### 4. **Apple 登录占位符**

```tsx
// 代码保留，便于以后启用
{/* Uncomment when ready to enable */}
{/* <button onClick={handleAppleLogin}>
    [Apple Logo] 使用 Apple 登录
</button> */}
```

**优势**:
- 代码已准备好
- 取消注释即可启用
- 不占据当前空间

## 🔄 交互流程

### 流程 1: OTP 登录（主流程）

```
1. 用户访问登录页
   ↓
2. 看到 Google 登录（最突出）
   ├→ 点击 Google → 跳转授权 → 登录成功
   └→ 不想用 Google
      ↓
3. 输入手机号或邮箱
   ├→ 输入手机号 → 自动格式化 → 提示"发送短信"
   └→ 输入邮箱 → 提示"发送邮件"
      ↓
4. 点击"发送验证码"
   ↓
5. 页面切换到验证码输入界面
   - 显示发送目标（手机号/邮箱）
   - 6位验证码输入框（自动聚焦）
   - 60秒倒计时
   ↓
6. 输入验证码 → 验证 → 登录成功
```

---

### 流程 2: 密码登录（备选流程）

```
1. 用户访问登录页
   ↓
2. 点击"使用密码登录"（折叠按钮）
   ↓
3. 展开表单
   - 邮箱输入框
   - 密码输入框
   - 眼睛图标（显示/隐藏密码）
   - "忘记密码？"链接
   ↓
4. 填写并提交 → 登录成功
```

## 🔧 技术实现

### 智能检测逻辑

```typescript
const detectIdentifierType = (value: string): 'phone' | 'email' | null => {
    const cleaned = value.replace(/\D/g, '');

    // Phone: 10+ digits or starts with +1/1
    if (cleaned.length >= 10 || value.startsWith('+1') || value.startsWith('1')) {
        return 'phone';
    }

    // Email: contains @
    if (value.includes('@')) {
        return 'email';
    }

    return null;
};
```

---

### 手机号格式化

```typescript
const formatPhoneNumber = (value: string) => {
    const digits = value.replace(/\D/g, '');
    const limited = digits.slice(0, 11);

    if (limited.length === 0) return '';
    if (limited.length <= 1) return `+${limited}`;
    if (limited.length <= 4) return `+${limited[0]} (${limited.slice(1)}`;
    if (limited.length <= 7) return `+${limited[0]} (${limited.slice(1, 4)}) ${limited.slice(4)}`;
    return `+${limited[0]} (${limited.slice(1, 4)}) ${limited.slice(4, 7)}-${limited.slice(7)}`;
};

// 输入: 6135551234
// 输出: +1 (613) 555-1234
```
