# 📱 手机号登录 - 快速开始指南

5分钟内完成手机号登录功能集成！

---

## 🚀 快速开始（开发环境 - 无需 Twilio）

### 步骤 1: 启用 Phone Auth（1分钟）

1. 访问 Supabase Dashboard: https://supabase.com/dashboard
2. 选择你的项目
3. 进入 **Authentication** → **Providers**
4. 找到 **Phone** 部分
5. 切换 **Enable Phone Sign-up** 为 ON
6. 点击 **Save**（不需要填写 Twilio 凭证）

✅ 完成！现在可以使用测试手机号登录了。

---

### 步骤 2: 测试登录（2分钟）

1. 启动开发服务器:
   ```bash
   npm run dev
   ```

2. 访问登录页面: http://localhost:5173/login

3. 点击 **"手机号"** 标签

4. 输入测试号码:
   ```
   +1 (234) 567-8901
   ```
   （任何以 +1234567890 开头的号码都是测试号码）

5. 点击 **"发送验证码"**

6. **获取验证码**（2种方法）:

   **方法 A**: 使用固定验证码（开发环境）
   ```
   123456
   ```

   **方法 B**: 从 Supabase Dashboard 获取
   - 进入 **Authentication** → **Logs**
   - 找到最新的 `phone_verification` 事件
   - 点击查看详情，复制验证码

7. 输入验证码，点击 **"确认登录"**

✅ 登录成功！

## 📋 已实现的功能

### ✅ 用户体验
- 手机号自动格式化（输入 `6135551234` → 显示 `+1 (613) 555-1234`）
- 60秒重发倒计时
- 实时错误提示
- 加载状态指示
- 友好的成功/失败提示

### ✅ 表单验证
- 加拿大手机号格式验证（+1 开头，10位数字）
- 区号首位不能是0或1
- 6位数字验证码
- 空值检测
- 非法字符过滤

### ✅ 安全特性
- 验证码60秒过期
- Rate limiting（防止滥发）
- 验证码只能使用一次
- 自动清理过期验证码

## 🔧 生产环境配置（可选）

如果要在**生产环境**使用真实短信，需要配置 Twilio：

### 1. 注册 Twilio
- 访问: https://www.twilio.com/try-twilio
- 免费试用账号提供 $15 额度（可发送 ~2000 条短信）

### 2. 获取凭证
- Account SID: `ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
- Auth Token: `xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
- Phone Number: 购买一个加拿大号码（$1/月）

### 3. 配置 Supabase
- 进入 **Authentication** → **Providers** → **Phone**
- 选择 **Twilio**
- 填写 Account SID, Auth Token, Phone Number
- 点击 **Save**

详细步骤请查看: [PHONE_AUTH_SETUP.md](./PHONE_AUTH_SETUP.md)

## 💡 手机号格式说明

### 自动格式化规则
```typescript
输入:  6135551234
输出:  +1 (613) 555-1234

输入:  16135551234
输出:  +1 (613) 555-1234

输入:  (613) 555-1234
输出:  +1 (613) 555-1234

输入:  1-613-555-1234
输出:  +1 (613) 555-1234
```

### 支持的输入方式
- ✅ `6135551234` - 10位数字
- ✅ `16135551234` - 11位数字（带1）
- ✅ `+16135551234` - 国际格式
- ✅ `(613) 555-1234` - 带括号
- ✅ `1-613-555-1234` - 带短横线
- ✅ 粘贴任意格式 - 自动提取数字

## 🐛 故障排查

### 问题: "SMS could not be sent"
**原因**: 生产环境未配置 Twilio
**解决**: 使用测试号码 `+1234567890` 或配置 Twilio

### 问题: "Invalid phone number"
**原因**: 手机号格式不正确
**解决**: 确保使用加拿大号码（+1 开头，10位数字）

### 问题: 收不到验证码
**开发环境**: 从 Supabase Dashboard → Logs 获取
**生产环境**: 检查 Twilio Console → SMS Logs
